## Open points

- Pro mode: the old concept page (`concepts/standard-pro-modes`) now redirects to the quickstart. Pro mode exists only in the "May 2025" entry of What's new and in the migration section of the agentic-mode page: "Pro mode is only available in the `2025-05-01-preview` API, which is now retired." Card 04 teaches what pro mode was, because the exam outline names it. Cards 05 and 06 teach its successor.
- Prompt injection in image text: no Learn page says outright that text inside images must be extracted before Prompt Shields can see it. The Prompt Shields page says it "analyze[s] supplied text". The Azure OpenAI transparency note says only that Computer Use "screenshot inputs are untrusted by nature and may include malicious instructions". Card 12 therefore puts the extraction step into the scenario and takes the answer only from the Prompt Shields page.
- Brand rules: Learn has no dedicated "brand rules for generated images" guidance. Card 11 uses Custom categories (rapid), which the docs describe for content that breaks "the customers' own policies", for text and images. The generation-side tools (prompting, the edit API with several reference images) are not on a card.
- Image Analysis 4.0 (cards 07–09) is deprecated and retires on September 25, 2028. The cards say so. The migration guide points to GPT models in Foundry or Content Understanding as replacements.
