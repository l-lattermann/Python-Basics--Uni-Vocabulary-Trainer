# 4.7.4 Use prebuilt models

Course quality: clear — read, layout and the prebuilt catalogue are described concisely, though the tables are lists to memorise rather than explanations.
Cards: 10 (basic 8, mc 2, order 0). Additions: 2.
- 4.7.4-01: the course never names the model IDs used in code (`prebuilt-read`, `prebuilt-layout`). Source: https://learn.microsoft.com/en-us/azure/ai-services/document-intelligence/model-overview
- 4.7.4-05: current docs also list W-4 and 1095 tax models, and give the unified model's ID `prebuilt-tax.us`. Source: same page.
- The docs now say the general document model is "no longer supported" with all its capabilities in layout; this matches the course's deprecation note, so no addition.

Terms:
- Document analysis models: Read model (01), Layout model (02), General document model (03)
- Layout features: selection marks, tables, document structure, `keyValuePairs` (02)
- Financial and legal documents (04): Invoice, Receipt, Bank statement, Check, Pay stub, Credit card, Contract
- US tax documents (05): Unified US tax, W-2, 1098, 1099, 1040
- US mortgage documents (06): 1003 (URLA), 1004 (URAR), 1005, 1008, Closing disclosure
- Personal identification documents (07): ID document, Health insurance card, Marriage certificate
- Features of prebuilt models (08): Text extraction, Key-value pairs, Selection marks, Tables, Fields
- Prebuilt vs custom choice (09); unified US tax scenario (10)
