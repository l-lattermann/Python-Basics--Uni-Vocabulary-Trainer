 The main motivation for the development of this model was to predict the processing times and the degree of difficulty of control tasks in the interactions between humans and computers.


Q: What are the three stages of skill learning according to Fitts and Posner (1973)? [3.1 Memory Types and Cognitive Processes]
A:
  • Cognitive stage → high effort, conscious thinking (slow, error-prone)
  • Associative stage → practice improves speed & accuracy, partly unconscious
  • Autonomous stage → skill becomes automated, little active thought needed

Learning is an experiential process that changes behavior through cognitive and motor skill acquisition, mainly stored in procedural memory. Fitts and Posner’s model describes three stages: beginners rely on conscious control (cognitive), practice strengthens performance (associative), and with mastery, skills become automatic (autonomous), like playing the piano without deliberate effort.
Q: What is the Technology Acceptance Model (TAM), and which factors determine technology adoption? [3.2.2 Technology Acceptance Model]
A:
Definition: The Technology Acceptance Model (TAM) explains how users form intentions to adopt or reject a technology based on perceived usefulness and ease of use.
Origin: Developed by Davis (1989), grounded in social psychology and behavioral prediction theories.
Key factors:
  • Perceived usefulness: Belief that using the technology improves performance or productivity.
  • Perceived ease of use: Belief that the technology is easy to learn and operate with minimal effort.
Advantages:
 • Predicts user acceptance and behavioral intention effectively.
 • Helps designers focus on usability and practical benefits to improve adoption.
 • Applicable across diverse technologies and contexts.
Disadvantages:
 • Ignores emotional, cultural, and contextual influences on technology use.
 • Oversimplifies trust and long-term engagement factors.
 • Assumes rational decision-making, which may not always reflect real user behavior.
Q: What is the Skill–Rules–Knowledge (SRK) Model and what levels of action does it describe? [3.4 SRK Model]
A:
  • Definition: A model (Embrey, 2005) describing how human actions shift between automatic, rule-based, and knowledge-based behavior depending on experience and familiarity.
  • Levels:
 - Skill level → routine, automatic actions (e.g., typing on a keyboard without thinking). Involves verbalizing automatic actions, recognizing stimuli, executing stereotypical patterns.
 - Rule level → conscious selection of appropriate action patterns in known situations. Stimuli are linked to stored rules (e.g., following shortcuts, applying procedures).
 - Knowledge level → problem-solving in unfamiliar situations where neither automatic skills nor rules apply. Requires active reasoning and environmental analysis.
  • Design Implication: HCI systems should support all three levels — enabling automation for experts, clear rule-based navigation for intermediates, and flexible guidance for novices.

Q: What are the key models and principles linking cognition and motor skills in HCI? [3.4 Summary]
A:
  • Memory systems: sensory register, short-term, long-term → distribute task resources
  • Cognitive load measurement: questionnaires (e.g., NASA-TLX) + physiological methods
  • Decision time: Hick-Hyman law → more choices = slower responses
  • Speed–accuracy tradeoff: Fitts’ Law, Steering Law → movement time depends on distance, size, or path width
  • Bimanual coordination: Guiard’s model → nondominant sets reference, dominant executes
  • Skill–Rules–Knowledge model: describes how users internalize actions (automatic, rule-based, knowledge-based)
Q: What key factors influence user interaction design, acceptance, and trust in socio-technical systems? [4.1 Summary]
A:
Designing for interaction requires balancing usability for both occasional users and experts:
 • Occasional users → prioritize ease of learning, memory support, and simple task execution.
 • Experts → rely on automation and mastery of advanced features.

Human-computer interaction (HCI) involves multiple interaction styles, including commands, menus, forms, and direct manipulation. Ensuring usability and user acceptance is vital; this is evaluated through User Acceptance Testing (UAT), which verifies that systems function effectively in real use cases.

With ongoing digital transformation, designers must address new challenges in trust and data protection. Trust depends on system transparency, reliability, and ethical handling of user data, while data security ensures confidentiality and compliance with regulations like the GDPR. Together, these principles support safe, efficient, and user-centered system design.
Q: What are the seven stages of the Human Action Cycle in HCI? [4.1 Human Action Cycle]
A:
Goal Formation Stage
 1. Form goal – Define what you want to achieve.

Execution Stage
2. Form intention – Translate goal into intended actions.
3. Specify action sequence – Plan ordered steps.
4. Execute actions – Carry out the sequence.

Evaluation Stage
5. Perceive system state – Observe the results.
6. Interpret outcome – Compare perceived vs. expected results.
7. Evaluate outcome – Assess success relative to the original goal.

This model (Norman, 1988) illustrates how users bridge the Gulf of Execution (translating goals into actions) and the Gulf of Evaluation (understanding outcomes), forming the core of user-centered interface design.
Q: What are the three main types of human memory, and how do they differ? [3.1 Memory Types and Cognitive Processes]
A:
  • Sensory register → ultra-brief storage of raw sensory input (0.5–5 s)
  • Short-term memory → active, limited storage (15–30 s), ~4–9 chunks
  • Long-term memory → large capacity, permanent storage, slower access (~0.1 s)

Human memory consists of three interacting systems. The sensory register briefly stores unprocessed stimuli from the senses. Short-term memory (or working memory) actively processes limited amounts of information using mechanisms like chunking. Long-term memory serves as the central, durable store for facts, experiences, and skills, though with slower retrieval times.



Q: What are the main design challenges in developing ubiquitous computing systems? [4.2.1 Challenges for Design and Development]
A:
Definition: Ubiquitous computing design involves creating interconnected devices that function seamlessly across contexts, input/output modes, and display sizes.

Key challenges:
 • Location-based and context-sensitive data: Systems must adapt information dynamically to user context — including location, time, mood, and history.
 • Privacy: Designers must protect users from data misuse, wiretapping, and unauthorized access to personal networks.
 • Security: Balancing usability with secure authentication, especially on public or shared systems, presents a major design trade-off.
 • Universal monitoring: Continuous data collection and tracking can compromise user autonomy and freedom.
 • Resource consumption: Persistent connectivity increases energy demands — both on devices (e.g., smartphones) and supporting cloud infrastructure.

Ubiquitous computing design requires balancing personalization, privacy, and power efficiency while maintaining user trust and seamless interaction across devices and environments.
Q: What defines an interaction in HCI, and what are the main interaction styles? [3.1 Interaction Styles]
A:
  •  Definition: An interaction is a purposeful and reciprocal exchange of information between at least two actors, aimed at achieving a goal.
  •  Key point: Not every information transfer qualifies—true interaction requires mutual influence and intent.
  •  Primary interaction styles (Shneiderman, 1988):
 1. Command-based interaction
 2. Menu selection
 3. Form-based input
 4. Direct manipulation
  •  Additional styles: Natural language, gesture-based, voice-based, and multimodal interactions—used in modern systems to enhance intuitiveness and accessibility.
Q: What key questions guide data protection management, and how are they addressed? [4.1.1 Data Protection Management]
A:
  1.  Where should personal data be stored?
 • Data should be kept on secure networks with restricted access or on password-protected local devices.
 • When no longer needed, personal data must be deleted or anonymized.
  2.  Who manages privacy?
 • Privacy management may rest with the service provider or be shared with users via configurable privacy settings.
  3.  How is privacy to be protected?
 • Protection involves access controls, encryption, anonymization, and customizable visibility options on platforms like Facebook or LinkedIn.

Data protection management ensures that personal data are securely stored, responsibly handled, and protected through both technical safeguards and user control mechanisms.

Q: What is the NASA Task Load Index (TLX), and how does it measure cognitive load? [3.3 Measuring Cognitive Load]
A:
  • Method → subjective self-assessment questionnaire
  • 6 subscales → mental, physical, temporal demand, performance, effort, frustration
  • Scale → 0–100 (in 5-point intervals)

The NASA TLX is a widely used questionnaire for subjective measurement of cognitive load. It asks participants to rate six independent workload dimensions on a 0–100 scale. The combined profile gives a multidimensional assessment of task load, providing insight into perceived mental effort, stress, and performance.

Q: How does the System Usability Scale (SUS) measure usability? [1.2 Challenges in Human-Computer Interaction]
A:

 • 10 statements
 • 5-point Likert scale
 • ease of use
 • learnability
 • satisfaction

The System Usability Scale (SUS), developed by Brooke (1996), measures the perceived usability of a system or interface through 10 standardized statements. Users rate each item on a 5-point Likert scale ranging from “strongly disagree” to “strongly agree.” The items cover key aspects of usability, including ease of use, learnability, and overall user satisfaction, making SUS a widely adopted, quick, and reliable tool for comparative usability evaluation.
Q: What are common types of system-related errors in HCI according to Butz et al. (2022)? [4.1 System Errors]
A:
  • Capture errors – A rare action is replaced by a familiar one (e.g., entering the wrong website password).
  • Description errors – Similar or nearby actions get mixed up (e.g., pressing Ctrl + V instead of Ctrl + C).
  • Mode errors – Performing an action in the wrong system mode (e.g., accidentally closing a program).
  • Data-driven errors – Incorrect input caused by wrong data entry (e.g., mistyping a phone number).
  • Associated-action errors – Performing a similar but unintended action (e.g., saying “Come in” instead of “Hello” on the phone).
  • Loss-of-activation errors – Forgetting part of a planned action sequence (e.g., going to fetch something but forgetting what).

These illustrate how automation and routine behaviors can lead to systematic user interface failures in HCI.
Q: What are the six Gestalt laws of grouping and how are they applied in design? [2.2 Gestalt Laws]
A:
 • Proximity → nearby elements are grouped (e.g., product image with name/price)
 • Similarity → visually alike items form groups (e.g., same color for category items)
 • Closure → incomplete shapes perceived as whole (e.g., padlock logo)
 • Continuity → elements on a line/curve seen as related (e.g., guiding flow in layouts)
 • Common Fate → elements with shared movement/direction grouped (e.g., animations in sync with music)
 • Prägnanz (Good Figure) → complex forms simplified into basic shapes (e.g., simple logos like Nike or Apple)

The Gestalt laws of grouping describe how humans naturally organize visual input into coherent wholes. Designers use these principles to structure layouts, navigation, and icons, making digital products clearer, more intuitive, and visually appealing.

Q: What are the three main processors in the Model Human Processor, and how do they interact with memory? [1.3 Basic Models of Human Information Processing]
A:

 • perceptual processor → sensory stimuli
 • cognitive processor → rational processing & planning
 • motor processor → action execution
 • interaction with short- & long-term memory

In the Model Human Processor, the perceptual processor receives sensory stimuli via the sensory organs and temporarily stores them in the sensory register, using long-term memory to interpret input. The cognitive processor employs both short- and long-term memory to plan suitable actions, depending on stimulus intensity and representation. Finally, the motor processor translates these plans into physical responses, such as muscle movements or bodily reactions (e.g., tears). All three systems work simultaneously and interact dynamically with memory to support human information processing.
Q: What is the difference between preattentive and attentive perception, and how is it relevant in GUI design? [2.3 Attentive and Preattentive Perception]
A:
 • Preattentive perception → automatic, unconscious, ~200–250 ms, independent of number of stimuli
 • Features detected preattentively → color, shape, size, orientation, curvature, motion, depth
 • Attentive perception → conscious, requires focused attention, used when multiple features combine
 • Design relevance → enables pop-out effects, selective highlighting, guiding user attention

Preattentive perception occurs in the eye’s nervous system before conscious attention, allowing users to instantly detect simple features such as color or shape differences. In contrast, attentive perception requires deliberate focus to process combinations of features (e.g., brightness + shape). In GUI design, preattentive effects are used to highlight important elements or reduce visual load, while attentive processing is reserved for more complex tasks.

Q: What are the three types of cognitive load in Cognitive Load Theory (CLT)? [3.3 Measuring Cognitive Load]
A:
  • Intrinsic load → complexity of the task itself (e.g., typing characters on keyboard)
  • Extraneous load → imposed by poor design or unclear interface
  • Germane load → effort to build schemas & integrate knowledge (e.g., tutorials, guided practice)

Cognitive Load Theory (Sweller, 2020) explains how task performance and learning depend on the amount of cognitive load. Intrinsic load is determined by task complexity, extraneous load stems from the way information is presented, and germane load reflects the mental work required to form lasting schemas in long-term memory. Effective interface and learning design aim to reduce extraneous load and optimize germane load.

Q: What is priming in memory processes? [3.1 Memory Types and Cognitive Processes]
A:
  • Definition → memory enhancement by prior exposure
  • Mechanism → earlier stimulus influences later response
  • Effect → faster recognition, easier processing

Priming occurs when exposure to one stimulus unconsciously shapes the response to a subsequent stimulus. It facilitates recognition and processing efficiency, often without the individual being aware of the influence.


Q: What is the sensory register, and what are its main components? [3.1 Memory Types and Cognitive Processes]
A:
  • Definition → fleeting storage of raw sensory input
  • Duration → 0.5–1 s (visual), 4–5 s (auditory)
  • Registers → iconic (visual), echonic (auditory), haptic (touch)

The sensory register (sensory memory) temporarily stores unprocessed stimuli from the senses before conscious processing. It contains modality-specific sub-registers: iconic (sight), echonic (hearing), and haptic (touch). Stored data are passed to short-term memory, with support from long-term memory for recognition and pattern matching.


Q: What are the two main types of human errors in HCI according to Norman (2013)? [4.1 Human Error Types]
A:
  • Slips – Correct plan, wrong execution; caused by inattention or memory lapses (e.g., typing your old name by habit).
  • Mistakes – Wrong plan or goal; occur when the user deliberately performs an incorrect action under a false assumption (e.g., using an unvalidated bus ticket).

In HCI, slips relate to execution errors, while mistakes relate to decision or planning errors — both emphasizing the need for clear design feedback and error prevention mechanisms.

 • human

The four subdomains in the HCI development process are human, computer, usage, and context. Q: What are the five key design principles in HCI according to Norman? [4.1 HCI Design Principles]
A:
 1. Affordances – Indicate how an object can be used through its design (e.g., a chair invites sitting).
 2. Signifiers – Visual or auditory cues that guide user actions (e.g., icons, labels, sounds).
 3. Constraints – Limit user actions to prevent errors (e.g., only numbers allowed in a date field).
 4. Mapping – Logical relationship between controls and their effects (e.g., turning steering wheel right → car turns right).
 5. Feedback – Immediate system response to user actions, confirming successful interaction (too little or too much can confuse).

These principles ensure intuitive, safe, and efficient interaction between humans and interfaces.

Q: What is short-term memory (working memory), and how is it structured? [3.1 Memory Types and Cognitive Processes]
A:
  • Duration → 15–30 s retention
  • Capacity → ~4–9 chunks
  • Subsystems → phonological loop, visuo-spatial sketchpad, episodic buffer
  • Controller → central executive directs attention

Short-term memory functions like RAM, temporarily holding and processing information. It includes a phonological loop (language sounds), a visuo-spatial sketchpad (visual/spatial data), and an episodic buffer (multimodal integration linked to long-term memory). The central executive allocates attention. Chunking allows more efficient use of limited capacity, e.g., grouping credit card digits.
