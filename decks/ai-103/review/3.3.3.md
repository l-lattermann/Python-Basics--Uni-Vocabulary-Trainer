- 3.3.3-01: the course never says what "diarize" means. Diarization = identifying who spoke when, giving speaker-attributed transcripts. Source: https://learn.microsoft.com/en-us/azure/foundry-classic/openai/whats-new (October 2025 entry).

Speech-to-text models on the `/audio` API take at most a 25 MB audio file per request; streaming transcription goes to Realtime API models (`gpt-realtime-whisper`, `gpt-live-transcribe`). Source: https://learn.microsoft.com/en-us/azure/foundry/foundry-models/concepts/models-sold-directly-by-azure?pivots=azure-openai (Audio API, speech-to-text table).
