Q: What does Fitts’ Law explain in HCI and how is it applied? [3.4 Fitts’ Law]
A:
  • Definition: Movement time (MT) depends on distance to target (D) and target size (W).
  • Formula:
 MT = a + b · log₂(D / W + 1)
 - a = constant (baseline reaction time)
 - b = device/user speed factor
 - D = distance to target
 - W = target width
  • Index of Difficulty (ID): log₂(D / W + 1)
 - Larger D → harder to hit
 - Larger W → easier to hit
  • Design Implications:
 - Make buttons larger for faster usability.
 - Use screen edges as natural “stops” for mouse control.
 - Pop-up menus save time vs. dropdowns (shorter movement path).

Fitts’ Law shows the trade-off between speed and accuracy: targets that are closer and larger are faster to reach. It provides a predictive model for optimizing input devices and interface layout in HCI.

Q: What is the Steering Law in HCI and how is it applied? [3.4 Steering Law]
A:
  • Definition: Extends Fitts’ Law to constrained movements where the pointer must follow a path (like through a tunnel).
  • Formula:
 T = a + b · ∫(1 / W(s))ds
 - T = movement time
 - a, b = empirically determined constants
 - W(s) = path width at position s
 - ∫ = integral over the path length s
  • Concept: Narrower paths → slower movement; wider paths → faster movement.
  • Applications:
 - Navigating cascading (hierarchical) menus
 - Path-following in interfaces (sliders, gestures, tunnel tasks in VR)

The Steering Law predicts movement time for tasks constrained by path geometry, unlike Fitts’ Law, which assumes free pointing.

Q: What are the three types of cognitive load in Cognitive Load Theory (CLT)? [3.3 Measuring Cognitive Load]

Q: How does the Hick-Hyman law explain decision-making speed in HCI? [3.4 Decision Making and Speed]
A:
  • Everyday decisions use long-term memory for logical choices.
  • Hick-Hyman Law: decision time grows with number of choices.
 Formula: RT = a + b · log₂N
 - RT = reaction time
 - a = constant (baseline time)
 - b = multiplicative constant (depends on context)
 - N = number of alternatives
  • Logarithmic relationship: each doubling of choices increases decision time by a constant.
  • Application in HCI:
 - Long, unsorted menus = slower decisions
 - Grouping or sorting (alphabetical, categories) = faster decisions

The Hick-Hyman law shows that decision time increases with the entropy of available alternatives. In interface design, this principle underlines the importance of structured menus, categorized options, and reduced clutter to minimize user response times and improve usability.
