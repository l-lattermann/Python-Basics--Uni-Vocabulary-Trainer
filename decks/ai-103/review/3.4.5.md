# 3.4.5 Configure audio format and voices

Course quality: thin. The unit shows the two SpeechConfig calls with one example each. It does not explain what the enum names mean, what the default voice is, or how a voice in SSML interacts with the SpeechConfig voice.
Cards: 2 (basic 1, mc 1). Additions: 2.

Terms:
- Output format criteria (list): audio file type, sample rate, bit depth → 3.4.5-01
- SpeechConfig / `set_speech_synthesis_output_format` / SpeechSynthesisOutputFormat → 3.4.5-01
- Voice name parts (locale, person's name, other details) → 3.4.5-02
- `speech_synthesis_voice_name` → 3.4.5-02

- 3.4.5-01 addition: raw formats (e.g. `Raw24Khz16BitMonoPcm`) carry no audio header; source https://learn.microsoft.com/en-us/azure/ai-services/speech-service/how-to-speech-synthesis?pivots=programming-language-python
- 3.4.5-02 addition: no voice name or synthesis language → default en-US voice; an SSML voice overrides both settings; same source.
- The module assessment (3.4.9, Q3) asks how to change the voice. 3.4.5-02 is phrased as a scenario on the name format so it does not duplicate that mc.
